# Enterprise Knowledge Voice Assistant

> **Live demo:** `https://enterprise-knowledge-assistant.onrender.com`  
> *(Replace with your Render URL after deployment)*

An AI-powered voice/text knowledge assistant for enterprise HR, IT and Compliance.  
Built with FastAPI, LangGraph, Groq (Llama 3.1), Qdrant, Neo4j GraphRAG, Redis and Docker.

## Deploy to Render (free, ~5 minutes)

### Step 1 – Push to GitHub
```bash
git init
git add .
git commit -m "feat: enterprise knowledge assistant v2"
git remote add origin https://github.com/YOUR_USERNAME/enterprise-knowledge-assistant.git
git push -u origin main
```

### Step 2 – Create Render service
1. Go to [dashboard.render.com](https://dashboard.render.com) → **New → Blueprint**
2. Connect your GitHub repo
3. Render reads `render.yaml` automatically

### Step 3 – Set environment variables
In the Render service dashboard → **Environment**:

| Key | Value |
|-----|-------|
| `GROQ_API_KEY` | Your key from [console.groq.com](https://console.groq.com) |
| `JWT_SECRET` | Auto-generated by Render (or paste your own 32-char secret) |

### Step 4 – Deploy
Click **Deploy**. Your app will be live at:
```
https://enterprise-knowledge-assistant.onrender.com
```

> **Note:** Render free tier sleeps after 15 min inactivity. First request after sleep takes ~30 s to wake.  
> To prevent this, ping it with [UptimeRobot](https://uptimerobot.com) (free).

## Architecture

```
Browser (voice in / voice out)
    │
    ├─ POST /api/auth/token       JWT login
    ├─ POST /api/chat             ← main pipeline
    │     Cache hit?  → return immediately
    │     embed_one(query)        TF-IDF (offline) / ST (prod)
    │     vector search           in-memory + RBAC filter
    │     GraphRAG                Neo4j / in-memory approval chains
    │     rerank                  keyword boost / CrossEncoder (prod)
    │     LLM generate            Groq (Llama 3.1) → citation-or-refuse
    │     audit.jsonl append
    │     → JSON response
    ├─ POST /api/ticket           confirmation-gated action
    ├─ GET  /api/analytics        manager+ only
    └─ POST /api/admin/ingest/*   hr_admin only; text + PDF
```

## Tech stack

- **Backend:** Python 3.12, FastAPI, Pydantic v2, uvicorn
- **LLM:** Groq (Llama-3.1-8b-instant) — free, 500 req/day
- **Retrieval:** TF-IDF in-memory → swappable to Qdrant + SentenceTransformer
- **GraphRAG:** In-memory approval chains → swappable to Neo4j
- **Auth:** JWT (python-jose) + sha256_crypt (passlib)
- **Deploy:** Docker, Render free tier
- **CI:** GitHub Actions (test + docker build on every push)

## Production upgrade path

All upgrades are drop-in; no other code changes needed.

| Swap | How |
|------|-----|
| Better embeddings | Set `SENTENCE_TRANSFORMERS=1` in env — `embedding.py` auto-switches |
| Persistent vector search | Set `QDRANT_URL=...` — `vector_store.py` auto-switches |
| Semantic cache | Set `REDIS_URL=...` — `cache.py` auto-switches |
| Real org chart | Set `NEO4J_URI/USER/PASS` — `graph.py` auto-switches |
| On-prem LLM | Set `LLM_BASE_URL=http://vllm:8000/v1` — `llm.py` auto-switches |
| SSO / LDAP | Replace `_USERS` dict in `auth.py` with your LDAP call |
